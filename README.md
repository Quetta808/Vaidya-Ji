# Ayurvedic & Homeopathic Store

A modern online medicine store website built with Next.js.

## Features

- Ayurvedic Products
- Homeopathic Products
- Customer Login/Signup
- Product Search & Filter
- WhatsApp Order Button
- Delivery Tracking
- Admin Dashboard
- Mobile Friendly Design

## Pages

- Home
- Products
- About
- Contact
- Cart
- Login
- Admin Panel

## Technology

- Next.js
- React
- Tailwind CSS
- MongoDB
